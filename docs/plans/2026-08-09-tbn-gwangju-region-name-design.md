# TBN 광주 지역명 변경 대응 설계

## 문제

TBN 광주 편성표의 선택 지역 표기가 `광주`에서 `전남광주`로 변경됐다. 파서는 요청한
지역의 페이지인지 확인하기 위해 선택 지역명을 고정값과 비교하므로 광주 수집만
`TbnSchemaError`로 실패한다.

## 설계

TBN이 현재 제공하는 공식 표기와 일치하도록 광주 지역명 계약을 `전남광주`로 갱신한다.
페이지 코드와 요청 날짜 검증은 그대로 유지해 다른 지역 페이지를 잘못 수집하는 것을
막는다. 실제 응답의 핵심 구조를 반영한 fixture를 추가하고 광주 페이지가 정상 파싱되는지
회귀 테스트로 고정한다.

## 검증

광주 회귀 테스트가 변경 전 실패하고 변경 후 통과하는지 확인한다. 이후 TBN adapter 테스트,
전체 Python 테스트, Ruff와 ty 검사를 실행한다.
